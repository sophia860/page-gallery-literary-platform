# Contributing to Page Gallery Literary Platform

Thank you for your interest in contributing to Page Gallery! This document provides guidelines and information for contributors.

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- A clear, descriptive title
- Steps to reproduce the problem
- Expected behavior vs actual behavior
- Browser and OS information
- Screenshots if applicable

### Suggesting Features

We welcome feature suggestions! Please open an issue with:
- A clear description of the feature
- Why this feature would be useful
- Any examples or mockups if available

### Pull Requests

1. **Fork the repository** and create your branch from `main`
2. **Make your changes** with clear, descriptive commit messages
3. **Test your changes** in multiple browsers if possible
4. **Update documentation** if you're changing functionality
5. **Submit a pull request** with a clear description of changes

## Development Setup

1. Clone your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/page-gallery-literary-platform.git
   ```

2. Open the project in your preferred code editor

3. Open `editor-dashboard.html` in a browser to test changes

## Code Style Guidelines

### HTML
- Use semantic HTML5 elements
- Include proper accessibility attributes (ARIA labels, alt text)
- Use 2-space indentation

### CSS
- Use CSS custom properties (variables) for colors and common values
- Follow BEM naming convention where applicable
- Keep selectors specific but not overly nested

### JavaScript
- Use descriptive function and variable names
- Comment complex logic
- Avoid global variables when possible
- Use ES6+ features supported by modern browsers

## Commit Message Guidelines

- Use present tense ("Add feature" not "Added feature")
- Use imperative mood ("Move cursor to..." not "Moves cursor to...")
- Keep the first line under 50 characters
- Reference issues when applicable ("Fix #123")

## Code of Conduct

Please be respectful and constructive in all interactions. We're building a platform for literary arts, and we value thoughtful, considerate communication.

## Questions?

Feel free to open an issue with questions or reach out to the maintainers.
